Как работает доставка коробов на СЦ

Реальные экраны программы в том порядке, в каком идёт работа: от заявки клиента до сдачи на СЦ. У каждого раздела помечена роль — {% if my_roles %}ваши разделы подсвечены в оглавлении{% else %}выберите свою{% endif %}.

Заявка→Этикетки→Забор→Склад МВБ→Паллеты→Рейс→Погрузка→Сдан на СЦ
{{ head(1, 'login', 'Вход и регистрация') }}

У МВБ свой вход: <адрес программы>/mvb/login. Сотрудникам логин и пароль выдаёт оператор или администратор. Клиент регистрируется сам.

{{ shot('01_login.png', 'Вход в МВБ', True) }}
Вход для клиентов, водителей и склада.
  1. Новый клиент жмёт «Зарегистрироваться» и заполняет компанию, адрес забора, телефон, логин и пароль.
  2. Оператор подтверждает клиента в разделе «Клиенты». До подтверждения войти нельзя.
{{ shot('02_register.png', 'Регистрация клиента', True) }}
Регистрация клиента.
{{ head(2, 'order', 'Новая заявка') }}

Одна заявка — один адрес забора и сколько угодно направлений. У каждого направления своя дата слота и количество коробов.

  1. «+ Новая заявка» → «Сколько направлений в заявке?».
  2. По каждому направлению: куда (Wildberries, Ozon или фулфилмент) → город → для ФФ его название → дата слота → коробов.
  3. Способ передачи: забор транспортной компанией (адрес и зона забора) или самопривоз.
  4. «Сохранить», затем «Оформить и присвоить штрихкоды».
  5. «🖨 Этикетки на все короба» — наклейте этикетку на каждый короб.
{{ shot('03_order_form.png', 'Форма заявки', True) }}
Форма заявки на телефоне.
⚠️
Короб без этикетки не принимается. У каждого короба свой штрихкод: по нему его сканируют на каждом этапе.
{{ head(3, 'my-orders', 'Мои заявки и данные водителя для пропуска') }}

В «Моих заявках» видно, где каждый короб, и стоимость. Когда назначен рейс на СЦ, в заявке появляются данные водителя для пропуска.

{{ shot('04_my_orders.png', 'Мои заявки', True) }}
Список заявок. «🚚 Данные водителя для пропуска есть» — пора заказывать пропуск.
{{ shot('05_order_detail.png', 'Заявка и данные водителя', True) }}
Жёлтый блок: водитель, который везёт на СЦ, госномер и авто. «Скопировать» — для вставки в кабинет маркетплейса.
ℹ️
Дату слота можно поменять в заявке, пока короба направления не уехали на СЦ.
{{ head(4, 'clients', 'Клиенты') }}

Новые регистрации и все клиенты в одном разделе. Число на кнопке меню — сколько клиентов ждут подтверждения.

{{ shot('06_clients.png', 'Клиенты') }}
Подтвердите или отклоните регистрацию; клиента можно завести и вручную.
{{ head(5, 'orders', 'Заявки в работе') }}

Все заявки клиентов. Новые заявки на забор без водителя подсвечены — назначьте водителя прямо из списка.

{{ shot('07_orders_operator.png', 'Заявки в работе') }}
Колонка «Водитель»: выберите и нажмите OK.
💰
Стоимость считается по прайсу при оформлении: забор по зоне, отправка на СЦ по городу, палетирование — от 10 коробов заявки на паллетах (цена × число паллет по 20 коробов), меньше 10 — бесплатно. В заявке её можно поправить или «Пересчитать по прайсу».
📦
Свои короба из WMS — перемещения WMS на склады WB и Ozon, ожидающие передачи в МВБ, показаны отдельным блоком прямо здесь, над списком заявок (без переклейки этикеток). Отметьте перемещения и нажмите «Передать» — получится одна заявка на склад-отправитель, дата слота берётся из «Даты поставки». Можно и без кнопки: скан этикетки WMS при заборе или приёмке сам передаёт перемещение.
{{ head(6, 'pickup', 'Забор у клиента') }}

В «Заявках на забор» водитель видит клиента, адрес, телефон и количество коробов. Свободные заявки по дороге можно взять кнопкой «Заберу».

  1. У клиента — «📷 Забрать» и сканируйте каждый короб.
  2. Когда отсканированы все короба, нажмите «Готово» (раньше не даст).
  3. Вся заявка не влезает в машину — отсканируйте то, что взяли, и нажмите «Не влезает — забрал часть»: остаток вернётся в заявки на забор.
  4. Привезли на склад — «Короба сданы в МВБ»: все забранные короба встанут на склад.
{{ shot('09_driver.png', 'Экран водителя', True) }}
Экран водителя. Пока у водителя есть рейс на СЦ, свободные заявки по дороге не показываются.
{{ shot('10_scan_pickup.png', 'Скан забора', True) }}
Скан сканером или камерой телефона (кнопка 📷).
{{ head(7, 'receive', 'Приёмка на складе') }}

Поштучная «📷 Приемка» нужна для самопривоза и для коробов, вернувшихся с СЦ. Короба от водителя встают на склад его кнопкой «Короба сданы в МВБ».

⚠️
Короб не может перескочить этап, повторный скан не задваивает учёт.
{{ head(8, 'pallets', 'Паллеты') }}

Короба одного направления собираются на паллету сканом. На экране паллеты — все короба этого направления на складе.

{{ shot('11_pallet.png', 'Паллета') }}
Зелёным — уже на этой паллете, жёлтым — на другой, без цвета — ещё не отсканирован.
💰
Палетирование (по умолчанию 500 ₽) делится между клиентами по доле их коробов на паллете и само попадает в стоимость заявок.
{{ head(9, 'dispatch', 'К отправке и рейс') }}

«К отправке» показывает, что лежит на складе по каждому направлению и дате слота. Отметьте направления и нажмите «Сформировать рейс» — заявки не делятся между машинами.

{{ shot('12_dispatch.png', 'К отправке') }}
Программа считает, сколько машин нужно.
  1. В рейсе впишите госномер, модель авто, ФИО и телефон водителя, план подачи и погрузки.
  2. «Назначить на рейс» — данные водителя сразу видны клиентам для пропуска.
  3. Отправьте водителю ссылку: по ней он без входа видит маршрут и отмечает точки.
{{ shot('13_trip.png', 'Рейс') }}
Страница рейса: маршрут, план и факт, авто и водитель, ссылка для водителя.
{{ head(10, 'loading', 'Погрузка') }}

Кладовщик открывает «📦 Погрузка», выбирает авто по госномеру и жмёт «Начать погрузку».

  1. Сканируйте паллеты (или отдельные короба) — каждый короб сам встанет на свою точку маршрута.
  2. «Завершить погрузку» — рейс уходит в путь.
{{ shot('14_loading.png', 'Погрузка') }}
Выбор авто по госномеру.
{{ head(11, 'sc', 'Водитель на СЦ') }}

По ссылке водитель видит на каждой точке только адрес (кнопка открывает маршрут в Яндекс Картах) и сколько паллет и коробов сдать.

{{ shot('15_sc_driver.png', 'Экран водителя на СЦ', True) }}
«✓ Сдан на СЦ» на каждой точке. Не приняли — «Не приняли?» с причиной, короба вернутся на склад.
{{ head(12, 'reports', 'Отчёт') }}

За период: по каждому клиенту заявки, короба по этапам и стоимость (забор, отправка, палетирование), ниже — по заявкам с датой, и отдельным блоком «По водителям» — кто сколько коробов забрал и по каким заявкам (по дате скана забора). Выгрузка в Excel — тремя листами.

{{ shot('16_reports.png', 'Отчёт') }}
{{ head(13, 'settings', 'Настройки: прайс и транспорт') }}

«⚙ Настройки» → «Прайс», «Водители», «Машины для СЦ», «Пользователи».

  1. Города и прайс отправки на СЦ: у города свои ступени «от N коробов — цена за короб», одинаковые для WB, Ozon и ФФ этого города.
  2. Пункты назначения: куда (WB / Ozon / ФФ) → город → название ФФ и адрес СЦ для маршрута. Из них клиент выбирает направление.
  3. Водители на забор: оператор заводит ФИО, закреплённое авто (модель, госномер, сколько коробов вмещает), придумывает логин и пароль и выдаёт их водителю. Сам водитель не регистрируется.
  4. Зоны забора (Черкесск, Регионы, Хабез, Отрадная) — фиксированная цена забора; палетирование — цена за паллету, порог для клиента (от 10 кор.) и максимум коробов на паллете (20). Пункты назначения: WB, Ozon, Lamoda, Яндекс Маркет, ФФ.
{{ shot('17_prices.png', 'Прайс') }} {{ shot('18_vehicles.png', 'Машины для СЦ') }}
Машины для СЦ: наёмные машины без штатного водителя. Водители и их авто заводятся только в «Водители».
🗑
Администратор может удалить заявку, рейс или паллету в любом статусе. Удаление не отменить.
{{ head(14, 'checklist', 'Памятка') }}

Каждый день

  • Оператор: подтвердить новых клиентов, назначить водителей на забор.
  • Водитель: отсканировать все короба на заборе, «Готово», на складе — «Короба сданы в МВБ».
  • Кладовщик: собрать паллеты по направлениям.
  • Оператор: «К отправке» → рейсы по слотам, вписать авто и водителя, отправить ссылку.
  • Кладовщик: погрузка сканом паллет, «Завершить погрузку».
  • Водитель на СЦ: «Сдан на СЦ» на каждой точке.
