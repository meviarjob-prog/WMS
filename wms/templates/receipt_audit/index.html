Проверка непринятых перемещений (Ozon)

Только для администратора. Сверка идёт по отчётам Ozon о приёмке (xlsx), загруженным пачкой.
Что делает проверка. Для каждого непринятого перемещения на Ozon находит его отчёт и сравнивает с отправленным:
  • Совпало — проводим как принятое.
  • Не хватает товара (излишков нет) — исправляем: короба, которых нет в отчёте, возвращаем на склад-отправитель, в пришедших коробах ставим принятое количество.
  • Ручная проверка — излишек, нераспознанные позиции, нет заявки на МП, а также случаи, когда в одном перемещении не хватило товара, а в другом тот же товар оказался лишним (вероятная ошибка при отправке). Ничего не меняется.
Сначала вы увидите результат и подтвердите применение. Прямого подключения к API Ozon в программе пока нет — данные берутся из файлов.
Можно выбрать сразу много файлов (supply-…-acceptance-report.xlsx).
