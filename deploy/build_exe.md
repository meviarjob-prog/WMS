# Сборка WMS.exe (Windows)

Собирает всю программу (сервер + автоматическая HTTPS-ссылка для камеры)
в один файл `WMS.exe`. Пользователю после сборки нужен только сам `.exe` —
Python и остальные зависимости ставить не нужно.

Собирать нужно **на Windows** (PyInstaller собирает .exe только под ту ОС,
на которой запущен).

## 1. Подготовка

Установите Python 3.10+ и склонируйте/скачайте проект, затем в папке
проекта:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install pyinstaller
```

## 2. cloudflared.exe (для ссылки с камерой из любого места)

Без этого шага .exe соберется и будет работать **локально** (в своей
Wi-Fi/локальной сети), но не даст защищенную HTTPS-ссылку для доступа
с телефона из любой сети.

1. Скачайте `cloudflared-windows-amd64.exe` со страницы релизов:
   https://github.com/cloudflare/cloudflared/releases
2. Переименуйте скачанный файл в `cloudflared.exe`.
3. Положите его в корень проекта — рядом с `run.py` и `desktop.py`.

## 3. Сборка

Из корня проекта:

```powershell
pyinstaller deploy\desktop.spec --distpath dist --workpath build --noconfirm
```

Если `cloudflared.exe` не найден в корне проекта, сборка выведет
предупреждение и всё равно соберется — просто без автоматической
публичной ссылки.

## 4. Готовый файл

Результат — `dist\WMS.exe`. Это самостоятельный файл, его можно скопировать
на любой Windows-компьютер и запускать двойным щелчком без установки
Python.

При первом запуске рядом с `WMS.exe` создается папка `instance` с базой
данных — она сохраняется между перезапусками (это не временные файлы
PyInstaller, а постоянное хранилище программы). Не удаляйте эту папку,
если не хотите потерять данные.

## 5. Что выведет программа при запуске

```
WMS запущен локально: http://localhost:5000
Поднимаю защищенную ссылку (Cloudflare Tunnel)...
============================================================
Готово! Открой на любом устройстве (компьютер, телефон):
  https://случайное-имя.trycloudflare.com
```

Эту ссылку раздайте пользователям — она открывается из любой сети (не
только локальной) и работает с камерой на телефоне без предупреждений
браузера. Ссылка меняется при каждом перезапуске `WMS.exe`.

## Постоянная ссылка (не меняется при перезапуске)

Ссылка выше — одноразовая (quick tunnel): удобно для быстрого старта, но
её приходится раздавать заново после каждого перезапуска `WMS.exe`. Если
у вас есть домен, подключённый к Cloudflare (например, `wmsmeviar.ru`),
можно один раз настроить **постоянный** адрес вроде
`https://wms.wmsmeviar.ru` — он не меняется никогда, даже при
перезапуске компьютера. Логин на компьютерах и телефонах сохраняется в
самом браузере, поэтому пароль каждый раз вводить тоже не придётся.

### Настройка (один раз)

1. Зайдите на https://one.dash.cloudflare.com (Zero Trust) → в левом меню
   **Networks → Tunnels** → **Create a tunnel**.
2. Выберите тип **Cloudflared**, задайте имя (например, `wms`) → **Save tunnel**.
3. На экране «Install and run connector» вам не нужно ничего копировать
   в терминал — просто найдите поле с токеном (длинная строка после
   `--token`) и скопируйте **только сам токен** (без `cloudflared tunnel run --token`).
4. Нажмите **Next**. На экране **Public Hostname**:
   - Subdomain: `wms` (или любой)
   - Domain: выберите `wmsmeviar.ru` из списка
   - Service → Type: **HTTP**, URL: `localhost:5000`
   - **Save tunnel**.
5. В папке с `WMS.exe` создайте два текстовых файла (обычным блокнотом,
   без расширения `.txt` в конце — Windows иногда его дублирует, проверьте
   в проводнике «Показывать расширения файлов»):
   - **`cloudflared_token.txt`** — вставьте скопированный на шаге 3 токен,
     одной строкой, без пробелов и переносов.
   - **`cloudflared_url.txt`** — впишите итоговый адрес одной строкой,
     например: `https://wms.wmsmeviar.ru`

Всё — при следующем запуске `WMS.exe` в консоли появится:

```
Поднимаю постоянную ссылку (именованный Cloudflare Tunnel)...
============================================================
Готово! Ссылка постоянная — не меняется при перезапуске программы.
  https://wms.wmsmeviar.ru
```

Если файла `cloudflared_token.txt` нет — программа работает как раньше
(одноразовая ссылка), никакой донастройки не требуется. Оба файла нужны
только на том компьютере, где запущен `WMS.exe` (сервер) — на остальных
устройствах просто открывают постоянную ссылку в браузере.

**Важно**: `cloudflared_token.txt` — секрет уровня пароля от туннеля, не
публикуйте и не пересылайте его никуда, кроме как между вашими
компьютерами напрямую.

## Пересборка после изменения кода

Просто повторите шаг 3 — PyInstaller пересоберет .exe с учетом изменений.
Папка `build\` — это временный кэш сборки, её можно удалять и она пересоздается
автоматически.
