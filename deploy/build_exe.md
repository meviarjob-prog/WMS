# Сборка WMS.exe (Windows)

Собирает всю программу (сервер + автоматическая HTTPS-ссылка для камеры)
в один файл `WMS.exe`. Пользователю после сборки нужен только сам `.exe` —
Python и остальные зависимости ставить не нужно.

Собирать нужно **на Windows** (PyInstaller собирает .exe только под ту ОС,
на которой запущен).

## 1. Подготовка

Установите Python 3.10+ и склонируйте/скачайте проект, затем в папке
проекта:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install pyinstaller
```

## 2. cloudflared.exe (для ссылки с камерой из любого места)

Без этого шага .exe соберется и будет работать **локально** (в своей
Wi-Fi/локальной сети), но не даст защищенную HTTPS-ссылку для доступа
с телефона из любой сети.

1. Скачайте `cloudflared-windows-amd64.exe` со страницы релизов:
   https://github.com/cloudflare/cloudflared/releases
2. Переименуйте скачанный файл в `cloudflared.exe`.
3. Положите его в корень проекта — рядом с `run.py` и `desktop.py`.

## 3. Сборка

Из корня проекта:

```powershell
pyinstaller deploy\desktop.spec --distpath dist --workpath build --noconfirm
```

Если `cloudflared.exe` не найден в корне проекта, сборка выведет
предупреждение и всё равно соберется — просто без автоматической
публичной ссылки.

## 4. Готовый файл

Результат — `dist\WMS.exe`. Это самостоятельный файл, его можно скопировать
на любой Windows-компьютер и запускать двойным щелчком без установки
Python.

При первом запуске рядом с `WMS.exe` создается папка `instance` с базой
данных — она сохраняется между перезапусками (это не временные файлы
PyInstaller, а постоянное хранилище программы). Не удаляйте эту папку,
если не хотите потерять данные.

## 5. Что выведет программа при запуске

```
WMS запущен локально: http://localhost:5000
Поднимаю защищенную ссылку (Cloudflare Tunnel)...
============================================================
Готово! Открой на любом устройстве (компьютер, телефон):
  https://случайное-имя.trycloudflare.com
```

Эту ссылку раздайте пользователям — она открывается из любой сети (не
только локальной) и работает с камерой на телефоне без предупреждений
браузера. Ссылка меняется при каждом перезапуске `WMS.exe`.

## Пересборка после изменения кода

Просто повторите шаг 3 — PyInstaller пересоберет .exe с учетом изменений.
Папка `build\` — это временный кэш сборки, её можно удалять и она пересоздается
автоматически.
