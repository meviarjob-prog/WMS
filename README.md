# WMS — система управления складом

Веб-приложение на Python (Flask + SQLite) для складского учета: приемка товара
(количество), размещение в короба и по ячейкам отдельной операцией,
перемещение коробов между складами, печать термоэтикеток 58×40 мм, загрузка
номенклатуры и выгрузка отчетов в Excel.

## Возможности

- **Номенклатура**: список, добавление вручную, скачивание Excel-шаблона,
  импорт/обновление номенклатуры из заполненного шаблона, экспорт в Excel.
- **Склады и ячейки**: создание складов и ячеек хранения (стеллаж/полка/ряд и т.п.),
  печать этикеток ячеек.
- **Приемка товара**: создание документа приемки → добавление позиций
  (сканером штрихкода или ручным поиском "по вхождению") → завершение.
  Приемка — это только количество товара по складу в целом; упаковка в
  короба и расстановка по ячейкам в нее не входит и выполняется отдельно,
  операцией «Размещение».
- **Размещение товара**: отдельная операция, не привязанная к конкретной
  приемке — берет общий неразмещенный остаток принятого товара по складу,
  позволяет упаковать его в короба (короб генерируется автоматически, номер
  уникален, печать этикетки товара и короба) и расставить короба по ячейкам
  (сканом/вводом кода ячейки, печать этикетки ячейки). Здесь же можно
  доразместить в ячейку уже упакованные короба, которые приехали
  перемещением без ячейки. Выгружается в Excel.
- **Перемещение**: список коробов, едущих на один склад назначения. Короба
  сканируются один за другим и добавляются в список — весь товар внутри
  каждого короба переезжает вместе с ним; для каждого короба сразу можно
  указать ячейку на складе назначения (или оставить пустой и доразместить
  позже через «Размещение»). Журнал перемещений выгружается в Excel.
- **Печать этикеток 58×40 мм**: для товара — штрихкод + наименование; для
  короба — генерируемый номер короба в виде штрихкода; для ячейки — код ячейки
  в виде штрихкода. Каждая этикетка доступна как HTML-страница для печати из
  браузера (авто-открытие диалога печати) и как готовый PDF нужного размера.
- **Отчеты**: выгрузка приемок и перемещений в Excel с фильтром по складу и периоду.
- **Поиск товара**: по штрихкоду (сканер эмулирует клавиатуру + Enter) и
  вручную — поле с автокомплитом, поиск по вхождению в артикул/наименование/штрихкод.
- **Мобильная версия**: интерфейс адаптивный (открывается с телефона как
  обычный сайт), плюс сканирование штрихкода прямо камерой телефона (кнопка
  📷 у полей приемки и перемещения — свой сканер не нужен) и установка
  значка на экран телефона (PWA), см. раздел ниже.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python run.py
```

Приложение будет доступно на `http://localhost:5000`. База данных SQLite
создается автоматически в `instance/wms.db` при первом запуске.

## Печать этикеток на термопринтере 58×40 мм

Для каждой этикетки (товар / короб / ячейка) есть:

1. **HTML-страница печати** — открывается по кнопке "🖨 Этикетка", размер
   страницы задан точно 58×40 мм (`@page { size: 58mm 40mm; margin: 0; }`).
   При открытии автоматически вызывается диалог печати браузера — выберите
   термопринтер и печатайте без полей/масштабирования ("Actual size").
2. **PDF того же размера** (`.pdf`-версия каждой этикетки) — для случаев,
   когда удобнее отправить готовый PDF-файл напрямую в очередь печати
   термопринтера.

При упаковке короба доступна массовая печать этикеток всех товаров, которые
в него уложены (кнопка "Этикетки товаров" на карточке короба).

## Работа с телефона: сканирование камерой и установка на экран

Приложение открывается с телефона как обычный сайт (адаптивная верстка), и
дополнительно умеет сканировать штрихкод камерой телефона прямо в браузере —
без Bluetooth/USB-сканера — и устанавливаться на домашний экран как
приложение (PWA).

### Как открыть с телефона

1. Компьютер и телефон должны быть в одной Wi-Fi сети.
2. При запуске `python run.py` в консоли будет выведен адрес вида
   `http://192.168.х.х:5000` — его нужно открыть в браузере на телефоне.
3. Если Windows спросит про доступ по сети для Python — разрешить
   (иначе телефон не достучится до сервера через файрвол).

### Сканирование камерой (требует HTTPS)

Браузеры разрешают доступ к камере только по защищенному соединению
(HTTPS) — обычный `http://` с телефона камеру не откроет (это ограничение
самого браузера, не приложения). Чтобы включить HTTPS с самоподписанным
сертификатом для локальной сети:

```bash
# Linux/macOS:
WMS_HTTPS=1 python run.py

# Windows PowerShell:
$env:WMS_HTTPS="1"; python run.py
```

После этого на телефоне открывайте `https://<адрес>:5000` — браузер один
раз покажет предупреждение о небезопасном сертификате (это нормально для
самоподписанного сертификата в локальной сети), нужно нажать
"Дополнительно" → "Все равно перейти". Дальше кнопка 📷 рядом с полями
сканирования (приемка, перемещение) откроет камеру и после наведения на
штрихкод автоматически подставит значение в поле — как будто оно
отсканировано обычным сканером.

Без HTTPS кнопка 📷 покажет понятное сообщение об ошибке, но обычный ручной
ввод/поиск и подключенный физический сканер штрихкода (эмулирующий
клавиатуру) продолжают работать как обычно.

### Установка значка на экран телефона

- **Android (Chrome)**: меню (⋮) → "Добавить на главный экран" /
  "Установить приложение".
- **iPhone (Safari)**: кнопка "Поделиться" → "На экран «Домой»".

После этого WMS откроется отдельным окном без адресной строки браузера — как
обычное приложение.

## Типовой сценарий работы

1. **Склады и ячейки**: создайте склад(ы) и ячейки хранения (`Склады и ячейки`).
2. **Номенклатура**: скачайте Excel-шаблон, заполните артикул/штрихкод/
   наименование/ед. изм., загрузите файл через `Импорт из Excel` (или
   добавляйте товары вручную).
3. **Приемка**: создайте документ приемки, добавьте позиции сканером или
   поиском (только количество), завершите — товар зачислится в
   неразмещенный остаток склада.
4. **Размещение**: отдельным шагом (когда удобно, необязательно сразу же)
   создайте документ размещения на этот склад, возьмите нужное количество
   под упаковку, создайте короб(а), упакуйте, распечатайте этикетки,
   разместите короба по ячейкам (со сканом/вводом кода ячейки и печатью
   этикетки ячейки), завершите.
5. **Перемещение**: создайте список перемещения, укажите склад назначения,
   сканируйте короба один за другим — каждый добавляется в список со всем
   своим содержимым; для каждого короба сразу укажите ячейку на складе
   назначения (или оставьте пустой), завершите — короба переедут разом.
   Короб без ячейки можно доразместить позже через «Размещение».
6. **Отчеты**: выгрузите операции приемки, размещения и перемещения в Excel
   с нужными фильтрами.

## Структура проекта

```
wms/
  models.py               модели БД (склады, ячейки, номенклатура, неразмещенный
                           остаток, короба, документы приемки/размещения/перемещения)
  blueprints/              маршруты Flask по разделам
    main.py                 дашборд
    warehouses.py            склады и ячейки
    nomenclature.py          номенклатура, шаблон/импорт/экспорт Excel
    receiving.py             приемка товара (количество)
    placement.py             размещение (упаковка в короба + расстановка по ячейкам)
    movement.py               перемещение (список коробов на один склад)
    labels.py                 печать этикеток (HTML + PDF)
    reports.py                 отчеты (выгрузка в Excel)
    api.py                      поиск (автокомплит, штрихкод)
  utils/
    numbering.py             генерация номеров документов/коробов
    barcodes.py                генерация PNG-штрихкодов (Code128)
    labels_pdf.py               генерация PDF-этикеток 58×40 мм
    excel_io.py                 шаблон/импорт/экспорт Excel
    http.py                     безопасный Content-Disposition для не-ASCII имен файлов
  templates/, static/        HTML-шаблоны и статика (Bootstrap 5, автокомплит,
                              сканер камеры html5-qrcode, PWA-манифест и иконки)
```

## Технологии

Flask, Flask-SQLAlchemy, SQLite, openpyxl (Excel), python-barcode + Pillow
(штрихкоды), reportlab (PDF-этикетки), Bootstrap 5 (интерфейс), html5-qrcode
(сканирование камерой). Внешние JS/CSS-библиотеки хранятся локально в
`static/vendor/` — интернет для работы приложения не нужен (кроме HTTPS-варианта
запуска, который не требует интернета, а только сертификат, генерируемый на лету).
