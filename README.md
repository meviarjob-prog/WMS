# WMS — система управления складом

Веб-приложение на Python (Flask + SQLite) для складского учета: приемка товара,
хранение, перемещение между складами/ячейками, печать термоэтикеток 58×40 мм,
загрузка номенклатуры и выгрузка отчетов в Excel.

## Возможности

- **Номенклатура**: список, добавление вручную, скачивание Excel-шаблона,
  импорт/обновление номенклатуры из заполненного шаблона, экспорт в Excel.
- **Склады и ячейки**: создание складов и ячеек хранения (стеллаж/полка/ряд и т.п.),
  печать этикеток ячеек.
- **Приемка товара**: создание документа приемки → добавление позиций (сканером
  штрихкода или ручным поиском "по вхождению" с выпадающим списком) → упаковка
  товаров в короба (короб генерируется автоматически, номер уникален) → печать
  этикеток товара и короба → размещение короба в ячейке (сканом/вводом кода) →
  печать этикетки ячейки → завершение приемки. Все операции приемки выгружаются
  в Excel.
- **Перемещение**: перемещение короба (со всем его содержимым) между ячейками
  и складами по сканированию/вводу номера короба и кода ячейки назначения.
  Журнал перемещений выгружается в Excel.
- **Печать этикеток 58×40 мм**: для товара — штрихкод + наименование; для
  короба — генерируемый номер короба в виде штрихкода; для ячейки — код ячейки
  в виде штрихкода. Каждая этикетка доступна как HTML-страница для печати из
  браузера (авто-открытие диалога печати) и как готовый PDF нужного размера.
- **Отчеты**: выгрузка приемок и перемещений в Excel с фильтром по складу и периоду.
- **Поиск товара**: по штрихкоду (сканер эмулирует клавиатуру + Enter) и
  вручную — поле с автокомплитом, поиск по вхождению в артикул/наименование/штрихкод.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python run.py
```

Приложение будет доступно на `http://localhost:5000`. База данных SQLite
создается автоматически в `instance/wms.db` при первом запуске.

## Печать этикеток на термопринтере 58×40 мм

Для каждой этикетки (товар / короб / ячейка) есть:

1. **HTML-страница печати** — открывается по кнопке "🖨 Этикетка", размер
   страницы задан точно 58×40 мм (`@page { size: 58mm 40mm; margin: 0; }`).
   При открытии автоматически вызывается диалог печати браузера — выберите
   термопринтер и печатайте без полей/масштабирования ("Actual size").
2. **PDF того же размера** (`.pdf`-версия каждой этикетки) — для случаев,
   когда удобнее отправить готовый PDF-файл напрямую в очередь печати
   термопринтера.

При упаковке короба доступна массовая печать этикеток всех товаров, которые
в него уложены (кнопка "Этикетки товаров" на карточке короба).

## Типовой сценарий работы

1. **Склады и ячейки**: создайте склад(ы) и ячейки хранения (`Склады и ячейки`).
2. **Номенклатура**: скачайте Excel-шаблон, заполните артикул/штрихкод/
   наименование/ед. изм., загрузите файл через `Импорт из Excel` (или
   добавляйте товары вручную).
3. **Приемка**: создайте документ приемки, добавьте позиции сканером или
   поиском, создайте короб(а), распределите позиции по коробам, распечатайте
   этикетки, разместите короба в ячейках (со сканом/вводом кода ячейки и
   печатью этикетки ячейки), завершите приемку.
4. **Перемещение**: отсканируйте/введите номер короба, укажите склад и (по
   желанию) ячейку назначения — все содержимое короба переместится целиком.
5. **Отчеты**: выгрузите операции приемки и перемещения в Excel с нужными
   фильтрами.

## Структура проекта

```
wms/
  models.py               модели БД (склады, ячейки, номенклатура, короба, документы)
  blueprints/              маршруты Flask по разделам
    main.py                 дашборд
    warehouses.py            склады и ячейки
    nomenclature.py          номенклатура, шаблон/импорт/экспорт Excel
    receiving.py             приемка товара
    movement.py               перемещение
    labels.py                 печать этикеток (HTML + PDF)
    reports.py                 отчеты (выгрузка в Excel)
    api.py                      поиск (автокомплит, штрихкод)
  utils/
    numbering.py             генерация номеров документов/коробов
    barcodes.py                генерация PNG-штрихкодов (Code128)
    labels_pdf.py               генерация PDF-этикеток 58×40 мм
    excel_io.py                 шаблон/импорт/экспорт Excel
  templates/, static/        HTML-шаблоны и статика (Bootstrap 5, автокомплит)
```

## Технологии

Flask, Flask-SQLAlchemy, SQLite, openpyxl (Excel), python-barcode + Pillow
(штрихкоды), reportlab (PDF-этикетки), Bootstrap 5 (интерфейс).
